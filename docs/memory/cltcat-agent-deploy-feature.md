**VERIFIED org API facts (v67, probed 2026-08-20 — do not re-derive):**
- **No supported API to push a file into the ADL.** No `/ssot` or `/connect` file-upload endpoint (all 404), no `ConnectApi` ingestion class (`ConnectApi.Datacloud` = CDP *query* only), Directory-Table DMOs not DML-writable, no external S3 data stream. → **file upload is a manual UI step** (Data Cloud → Data Library → Add files).
- **Re-index is automatic:** search index `processingType: REALTIME` → refreshes when the directory table changes. No rebuild call.
- **Readiness is pollable (supported):** `GET /services/data/v67.0/ssot/search-index` → entry `developerName=="ADL_Help_Agent_1_Da"` → `runtimeStatus` (`READY`) + `indexRefreshedOn`. Also platform events `SearchIndexJobStatusEvent`, `RTIndexAsyncStatusEvent`.
- `GenAiDataLibrary`/`GenAiRetriever` are **INVALID_TYPE at v67** → ADL/retriever are NOT source-controlled metadata; they ride the Trialforce snapshot.
- **Rebrand the embedded widget = Tooling API**, instant, no publish: PATCH `EmbeddedServiceBranding` / the `BrandingSet` `BrandingSetProperty` rows (`ConnectApi` has no branding writer). Full Experience-site *page* theme also editable via Tooling `BrandingSetProperty` BUT going live needs a **publish, and there is NO public publish API** (Builder UI only).
- **Templatization fragile links to validate per produced org:** SiteDotCom of the Embedded-Service LWR site "does not support MD API Retrieval"; MIAW deployment portability; a few Digital-Experience org prefs (e.g. `ExpBundleMetadataPref`); site may need re-publish per child org.

**GROUNDING PIVOT (2026-08-20):** abandoned the managed Data Library (no ingest API → manual upload). Instead ground the FAQ topic via a **custom Apex agent action** (the genAiFunction+Apex pattern the CLTs use) reading a runtime-written record — fully programmatic, instant, no upload/indexing/ssot. Grounding via context injection (fine for a bounded FAQ), not vector RAG.

**MORE VERIFIED org facts (2026-08-20):**
